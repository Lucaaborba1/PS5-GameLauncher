# PS5 Game Launcher

Canal público de distribuição para Windows e Companion Android.

## Downloads

Os instaladores, APK e notas ficam nas [releases](https://github.com/Lucaaborba1/PS5-GameLauncher/releases).

- Windows: instalador `PS5-Game-Launcher-Setup-Cinematico-VERSAO-PUBLICAR.exe`.
- Android: APK `PS5-Game-Launcher-Companion-vVERSAO.apk`.
- Quem já usa o launcher pode verificar atualizações em Configurações → Sistema.

Durante a transição do atualizador, um ASAR assinado acompanha o instalador para compatibilidade com versões antigas. O APK mantém sua identidade e assinatura existentes.

## Segurança e privacidade

O Security Center central depende de configuração do serviço HTTPS e autorização do usuário para registro da instalação. Sem essa configuração, não são enviados registros ao serviço central. O nome do computador é opcional.

O painel administrativo e o backend não são distribuídos neste canal. O desenvolvimento e seus backups permanecem privados. Este repositório contém apenas informações e arquivos de distribuição; os arquivos automáticos “Source code” das novas tags contêm somente esse material público.

O launcher preserva sua biblioteca e funcionalidades locais quando o servidor de segurança está indisponível. Um erro isolado de integridade não aplica punição automática.

Este projeto não é afiliado à Sony, Nintendo ou Valve. Licenças dos componentes distribuídos acompanham os respectivos pacotes.
